# ArchWiki (archwiki-query)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `archwiki`, which searches the ArchWiki and reads its pages.

- When you give a search term, the tool finds the best-matching page and opens it, and lists the other results at the end; if you only want the search results, use `action=search`.
- For a long page, the tool first gives the introduction and the sections that fit; the sections that do not fit are listed with their number, heading and length (sections below the third level are merged into their parent), and you can then fetch them with `section`.
- Code blocks, note and tip boxes, and tables are kept; edit links, the table of contents and the related-articles bar are removed.
- With `lang=zh`, the tool queries the Arch Linux Chinese community wiki (wiki.archlinuxcn.org). It is translated by the community, so its content may be older than the English wiki.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `query` | The search terms |
| `title` | The exact page title; when it is given, that page is opened directly (redirects are followed) |
| `action` | `auto` (default), `search` (list the results only), `page` (open by title) |
| `section` | Fetch only one section: by number (for example `2.1`) or by heading (for example `Troubleshooting`); its subsections are included |
| `lang` | `en` (default) or `zh` |
| `limit` | The number of search results to list, 1–20, default 8 |
| `max_chars` | The maximum number of characters of page text to return, 1000–40000, default 8000 |
| `format` | `md` (default) or `json` |

## Dependencies and notes

This section explains what the tool depends on and how it handles search results.

- The tool uses only the Python standard library and fetches content through MediaWiki's `api.php`.
- The ArchWiki's built-in full-text search ranks results poorly (for example, when you search for `nvidia suspend`, the first forty results are all laptop model pages), so when you search for several words, the tool also searches the titles for each word on its own, and pages whose titles match more of the words rank higher.
- In English mode, the tool filters out translated pages (pages whose titles end in a suffix such as `(Deutsch)`, and subpages written in a non-Latin script).
