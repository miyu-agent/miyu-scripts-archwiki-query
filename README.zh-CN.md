# ArchWiki（archwiki-query）

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `archwiki`，用来搜索 ArchWiki 和阅读页面。

- 给出搜索词时，工具会找到最匹配的页面并打开，其余结果列在末尾；如果只想看搜索结果，使用 `action=search`。
- 对于长页面，工具先给出导言和放得下的小节，放不下的小节会列出编号、标题和字数（三级以下的小节并进上一级），之后可以用 `section` 获取。
- 代码块、注意和提示框、表格会保留；编辑链接、目录和相关文章栏会去掉。
- 使用 `lang=zh` 时查询 Arch Linux 中文维基（wiki.archlinuxcn.org）。它由社区翻译，内容可能比英文版旧。

## 参数

这件工具接受下面这些参数：

| 参数 | 说明 |
|---|---|
| `query` | 要搜索的关键词 |
| `title` | 准确的页面标题，填写以后直接打开这个页面（遇到重定向会跟着跳转） |
| `action` | `auto`（默认）、`search`（只列出结果）、`page`（按标题打开） |
| `section` | 只获取一个小节：可以写编号（例如 `2.1`）或者标题（例如 `Troubleshooting`），结果包含它的子小节 |
| `lang` | `en`（默认）或者 `zh` |
| `limit` | 列出的搜索结果条数，1–20，默认 8 |
| `max_chars` | 正文最多返回的字数，1000–40000，默认 8000 |
| `format` | `md`（默认）或者 `json` |

## 依赖与注意

这一节说明工具依赖什么，以及它如何处理搜索结果。

- 工具只使用 Python 标准库，通过 MediaWiki 的 `api.php` 获取内容。
- ArchWiki 自带的全文搜索排序很差（例如搜索 `nvidia suspend` 时，前四十条结果都是笔记本型号的页面），所以搜索多个词时，工具会再用每个词单独搜索一遍标题，标题里命中的词越多，排得越靠前。
- 在英文模式下，工具会滤掉译文页面（标题带 `(Deutsch)` 这类后缀的页面，或者使用非拉丁文字的子页面）。
